# File Change Hotspot Reporter

This project helps you visualize which files in your repository change most often. By analyzing Git history, it identifies hotspots where changes are frequent, guiding you to focus on risky areas in your codebase. 

## How to Use
1. Clone the repository.
2. Run the script using Node.js to analyze the repository.
3. View the generated report in the browser.

## Requirements
- Node.js installed on your machine.

## Installation
```bash
npm install
```

## Run the Analyzer
```bash
node analyzer.js
```
